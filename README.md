# 🛒 RetailCo E-Commerce Analytics

End-to-end business intelligence project analyzing retail order data to drive business growth, optimize logistics, and improve customer satisfaction.

## 📌 Project Overview
This project is a complete end-to-end analytics solution designed to transform raw retail data into actionable business intelligence. It covers the full BI workflow:

* **Data Cleaning & Transformation**: Using SQL to prepare and model data.
* **Data Modeling**: Star schema implementation in Power BI.
* **Advanced Analytics**: DAX measures for sales, delivery, and customer sentiment.
* **Interactive Dashboard**: A multi-page Power BI dashboard for executive insights.
* **Executive Reporting**: A comprehensive PDF report with strategic recommendations.

## 📊 Key Business Insights
* **Total Revenue**: R$13.5M
* **Total Orders**: 99K
* **Avg Delivery Time**: 12.5 Days
* **Avg Review Score**: 4.09 / 5.0
* **Customer Base**: Highly dominated by "Loyal" segments.
